# Fuzail Kazi — Portfolio

Personal portfolio of Fuzail Kazi, an AI product manager and builder working across product engineering, developer relations, and go-to-market.

The site brings together:

- Work experience
- Product case studies
- Independent projects
- Writing and notes
- Career updates

## Built with

- Next.js
- TypeScript
- Tailwind CSS
- Deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To run the development server on port 3001 instead, use:

```bash
npm run dev -- --port 3001
```

Then open [http://localhost:3001](http://localhost:3001).

## Portfolio links

Set `NEXT_PUBLIC_SITE_URL` to the public origin (including `https://`) before building for production. It supplies social metadata and sitemap URLs; the sitemap stays empty when the domain is unset. Rebuild after changing it.

Set `RESUME_URL` to a public résumé PDF URL to show the download link. Without it, contact actions offer a résumé request by email.

The PM introduction and selected professional stories live in `content/pm-portfolio.ts`. The stories summarize existing experience; measurement windows, baseline values, and supporting screenshots still need source material before they can be added.
