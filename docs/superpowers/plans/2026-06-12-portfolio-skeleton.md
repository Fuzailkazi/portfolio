# Portfolio Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Initialize a new portfolio skeleton project using Next.js (App Router), Tailwind CSS (v4), TypeScript, static export, ESLint + Prettier, and Git.

**Architecture:** Create a modular structure where sections retrieve typed placeholder data from a central `content.ts` file. Customization of Tailwind v4 will be set up via CSS variables in `@theme` inside `app/globals.css`.

**Tech Stack:** Next.js 15, React 19, Tailwind CSS v4, TypeScript, ESLint, Prettier, npm.

---

### Task 1: Check create-next-app Options and Scaffold Application

**Files:**
